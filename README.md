# LeafTab（一叶）

一款面向 **Windows 10 x64（1903~22H2）与 Windows 11 x64** 的轻量级、无广告、零注入多标签资源管理器。

内部直接托管 Windows 官方公开的 `IExplorerBrowser`（`SHELLDLL_DefView`）原生视图控件，外层基于 `.NET Framework 4.8 + WPF` 打造与 **Windows 11 文件资源管理器**高度一致的多标签顶栏（保留左上角 LeafTab 专属绿叶图标）、可交互面包屑导航栏、命令栏、可折叠书签栏与状态栏。编译产物为**约 180 KB 的纯净单文件 `LeafTab.exe`**（系统自带运行时，零第三方 DLL 依赖）。

---

## 核心特性（v0.3.0）

- **Windows 11 原生感功能区设计**：
  - **连接式云母标签栏（Row 0）**：左上角保留 LeafTab 绿叶徽标；仅对顶部 38 DIP 标签栏启用 Win11 DWM Mica 云母材质，当前激活标签（`#F3F6FA`）与下方导航栏无缝融合；中间原生文件视图保持 `100%` 纯白不透明底色，确保 GDI ClearType 文件名锐利不发虚；
  - **双模面包屑与异步搜索栏（Row 1）**：支持 `后退 / 前进 / 向上 / 刷新`，双模面包屑地址框（点击层级跳转、中键层级后台开新标签、点击 `>` 弹出带图标的子目录列表、点击空白或 `Ctrl+L` 编辑完整路径、右侧 `☆` 一键收藏），以及右侧异步流式目录搜索框（基于原生 `IResultsFolder`，无索引服务依赖）；
  - **完整 Win11 命令栏（Row 2）**：提供 `⊕ 新建 ▾`（文件夹 / `.txt` / `.md` / `.zip` 并自动进入内联重命名）、`✂ 剪切` / `❐ 复制` / `📋 粘贴` / `[A|] 重命名` / `↪ 复制路径` / `🗑 删除`（随选中项与剪贴板实时启停）、`⇅ 排序 ▾`、`☰ 查看 ▾`（8 种视图尺寸 + 勾选**“文件扩展名”**与**“隐藏的项目”**）、`⋯` 更多菜单，以及最右侧 `◫ 预览` 窗格开关；
  - **可折叠书签栏（Row 3）与状态栏（Row 5）**：`Ctrl+Shift+B` 切换书签栏显隐（支持直接拖入文件夹收藏），底部状态栏实时展示总项目数、选中项目数与总字节大小，以及右下角 `[ ☰ | ⊞ ]` 详细信息/大图标快切。
- **高效多标签与会话管理**：
  - 支持**标签水平拖拽排序**、**`Ctrl+Shift+T` 恢复最近关闭标签**、每标签独立前进/后退历史栈；
  - 内置零依赖 `config.json` 会话与配置持久化，自动记忆窗口尺寸位置、上次打开的所有标签页与书签列表。
- **顺手的手势与跨标签拖放**：
  - **鼠标中键点击文件夹 / 磁盘分区**：后台新建标签打开（独立 MTA 后台线程调用 `CUIAutomation8` 命中，防 UI 线程重入死锁，非文件夹自动忽略）；
  - **鼠标左键双击文件区空白处**：返回上一级目录（精准排除文件项与分组标题栏）；
  - **跨标签拖拽文件**：拖起文件移至其他标签悬停约 `380ms` 自动切页，移入目标原生列表松手即可完成系统原生移动/复制；
  - **完整原生生态**：锁定 `x64` 进程，保留系统左导航树、第三方 64 位右键扩展（夸克网盘 / 7-Zip / Git / SVN）、缩略图、回收站与 WSL 命名空间，零注入独立运行。

## 快捷键与手势一览

| 快捷键 / 手势 | 功能 |
| :--- | :--- |
| `Ctrl + T` | 新建标签页 |
| `Ctrl + W` / 双击标签 / 中键点标签 | 关闭当前标签页 |
| `Ctrl + Shift + T` | 恢复最近关闭的标签页 |
| 按住标签左右拖动 | 调整标签页顺序 |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` / 标签栏滚轮 | 循环切换标签页 |
| `Ctrl + L` / `Alt + D` / `F4` | 聚焦并全选编辑完整路径 |
| `Ctrl + F` / `F3` | 聚焦右侧异步目录搜索框 |
| `Ctrl + D` | 将当前目录加入/移出书签栏 |
| `Ctrl + Shift + B` | 显示 / 隐藏书签栏 |
| `Ctrl + Shift + N` | 在当前目录新建文件夹并立即重命名 |
| `Ctrl + Shift + C` | 复制选中项完整路径到剪贴板 |
| `Alt + P` | 显示 / 隐藏右侧原生预览窗格 |
| `Alt + ←` / `Alt + →` / `Alt + ↑` | 后退 / 前进 / 向上一级 |
| `F5` | 刷新当前视图与系统显示状态 |
| 面包屑节点**中键点击** | 在后台新标签打开该上级目录 |
| 文件区**中键点击文件夹** | 在后台新标签打开该目录 |
| 文件区**左键双击纯空白处** | 返回上一级目录 |

## 编译与运行

### 环境要求
- Windows 10 x64（1903 及以上）或 Windows 11 x64（系统已内置 `.NET Framework 4.8`）
- 编译工具：Visual Studio 2022+（含 `.NET 桌面开发` 工作负载）或 MSBuild

### 命令行构建
```powershell
msbuild LeafTab.sln /t:Restore,Build /p:Configuration=Release /p:Platform=x64
```
生成的单文件可执行程序位于：
```text
src\LeafTab\bin\x64\Release\net48\LeafTab.exe
```

### 运行内置兼容性与资源自检
```powershell
Start-Process -FilePath .\src\LeafTab\bin\x64\Release\net48\LeafTab.exe -ArgumentList "--self-test","COMPATIBILITY_REPORT_RAW.md" -Wait
```
