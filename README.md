# LeafTab（一叶）

一款面向 **Windows 10 x64（1903~22H2）与 Windows 11 x64** 的轻量级、无广告、零注入多标签资源管理器。

内部直接托管 Windows 官方公开的 `IExplorerBrowser`（`SHELLDLL_DefView`）原生视图控件，外层基于 `.NET Framework 4.8 + WPF` 打造简约高级的 **Apple 风「极简云雾」液态玻璃（Liquid Glass）** 功能区、无滚动条自适应圆弧连接标签栏、极简无框悬浮命令栏、SF Symbols 双色调分层矢量图标体系、可交互面包屑与异步搜索舱。编译产物为**约 200 KB 的纯净单文件 `LeafTab.exe`**（系统自带运行时，零第三方 DLL 依赖）。

## 核心特性（v0.4.0）

- **「极简云雾」分区液态玻璃 UI 与 SF 双色调图标体系**：
  - **圆弧连接式液态玻璃标签栏（Row 0，零滚动条）**：左上角保留圆润白玻璃 LeafTab 绿叶徽标；采用自定义 `AdaptiveTabStripPanel` + `TabBarTrackPanel` 实现全宽自然舒展与多标签等比自适应压缩（**永不出现横向滚动条**），`[+]` 新建按钮紧贴末尾页签右侧；当前激活页签通过底部左右 `9px` 外翻内凹圆弧耳片（Concave Fillet）与下方毛玻璃导航层无缝融为一体；
  - **分区 DWM Desktop Acrylic 实时透光架构**：对顶部功能区（Row 0~3）与底部状态栏（Row 5）启用 `DWMSBT_TRANSIENTWINDOW` 桌面亚克力实时磨砂玻璃（叠加冷调云雾柔光渐变，Win10 自动优雅回退为清透云雾纯色），中间原生文件列表区（Row 4）严格保持 `100%` `#FFFFFF` 纯白不透明底色，确保 GDI ClearType 文件名锐利不发虚；
  - **悬浮白玻璃面包屑舱与异步搜索舱（Row 1）**：支持 `后退 / 前进 / 向上 / 刷新`，高透白玻璃圆角面包屑舱（点击层级跳转、中键后台开新标签、点击 `>` 弹出带原生图标的子目录菜单、点击空白或 `Ctrl+L` 切换果味蓝聚焦环完整路径编辑、右侧收藏星标智能隐现），以及右侧异步流式目录搜索舱（基于原生 `IResultsFolder`，不干扰主浏览视图滚动条）；
  - **极简无框悬浮命令栏 + SF 双色调图标（Row 2）**：重绘全套 `24×24` 光学网格贝塞尔双色调分层矢量图标（深岩灰主线 + `#007AFF` 果味蓝点缀与淡彩玻璃填充）；平时无生硬外框悬浮于毛玻璃底板之上，悬停时浮现高光白玻璃胶囊，涵盖 `⊕ 新建 ▾`（带系统原生文件/文件夹图标并自动进入内联重命名）、`剪切 / 复制 / 粘贴 / 重命名 / 复制路径 / 删除`、`排序 ▾`、`查看 ▾`（8 种视图尺寸 + 勾选**“文件扩展名”**与**“隐藏的项目”**）、`⋯` 更多菜单与右侧 `◫ 预览` 窗格；
  - **可折叠书签栏（Row 3）与毛玻璃状态栏（Row 5）**：`Ctrl+Shift+B` 切换书签栏显隐（支持拖入文件夹直接收藏），底部状态栏实时展示总项目数、选中项目数与字节大小，右侧配磨砂分段视图胶囊 `[ ☰ | ⊞ ]`。
- **丝滑无闪烁的切换与动效体验**：
  - **后台预热秒开页签池（Pre-Warmed Host Pool）**：空闲时静默预热 1 个「此电脑」原生宿主实例，点击 `+` 或按 `Ctrl+T` 直接瞬间接管并附带 `165ms CubicOut` 宽度展开与渐显动画，彻底消除冷启动白屏与灰底闪动；
  - **纯白无擦除宿主窗口类 + 全局状态栏裁剪缓存**：以自定义纯白背景 Win32 窗口类替代默认灰色 `Static` 容器，并缓存 `IExplorerBrowser` 内部状态栏裁剪高度，彻底根治切页灰闪与首次加载后的 `23px` 纵向跳变；
  - **面包屑柔滑过渡与原生焦点自动归还**：目录跳转附带 `135ms` 轻量化位移渐显过渡；点击顶栏按钮或关闭磨砂下拉菜单后自动通过 `IShellView::UIActivate` 归还原生列表焦点，保持文件选中高亮不失焦变灰。
- **顺手的手势、会话记忆与完整原生生态**：
  - 支持**标签水平拖拽排序**、**`Ctrl+Shift+T` 恢复最近关闭标签**、每标签独立前进/后退历史栈与零依赖 `config.json` 会话持久化；
  - **鼠标中键点击文件夹/磁盘分区**后台新开标签、**左键双击空白处**返回上级、**跨标签拖放文件悬停 `380ms` 自动切页**；
  - 锁定 `x64` 进程，完整保留系统左导航树、第三方 64 位右键扩展（夸克网盘 / 7-Zip / Git / SVN）、缩略图、回收站与 WSL 命名空间。

## 快捷键与手势一览

| 快捷键 / 手势 | 功能 |
| :--- | :--- |
| `Ctrl + T` | 秒开新建标签页（命中后台预热池） |
| `Ctrl + W` / 双击标签 / 中键点标签 | 关闭当前标签页 |
| `Ctrl + Shift + T` | 恢复最近关闭的标签页 |
| 按住标签左右拖动 | 调整标签页顺序 |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` / 标签栏滚轮 | 循环切换标签页 |
| `Ctrl + L` / `Alt + D` / `F4` | 聚焦并全选编辑完整路径 |
| `Ctrl + F` / `Ctrl + E` | 聚焦右侧异步目录搜索框 |
| `Ctrl + D` | 将当前目录加入/移出书签栏 |
| `Ctrl + Shift + B` | 显示 / 隐藏书签栏 |
| `Ctrl + Shift + N` | 在当前目录新建文件夹并立即重命名 |
| `Ctrl + Shift + C` | 复制选中项完整路径到剪贴板 |
| `Alt + ←` / `Alt + →` / `Alt + ↑` | 后退 / 前进 / 向上一级 |
| `F5` | 刷新当前视图与系统显示状态 |
| 面包屑节点**中键点击** | 在后台新标签打开该上级目录 |
| 文件区**中键点击文件夹** | 在后台新标签打开该目录 |
| 文件区**左键双击纯空白处** | 返回上一级目录 |

## 编译与运行

### 环境要求
- Windows 10 x64（1903 及以上）或 Windows 11 x64（系统已内置 `.NET Framework 4.8`）
- 编译工具：Visual Studio 2022+（含 `.NET 桌面开发` 工作负载）或 MSBuild

### 命令行构建
```powershell
msbuild LeafTab.sln /t:Restore,Build /p:Configuration=Release /p:Platform=x64
```
生成的单文件可执行程序位于：
```text
src\LeafTab\bin\x64\Release\net48\LeafTab.exe
```

### 运行内置兼容性与资源自检
```powershell
Start-Process -FilePath .\src\LeafTab\bin\x64\Release\net48\LeafTab.exe -ArgumentList "--self-test","COMPATIBILITY_REPORT_RAW.md" -Wait
```
