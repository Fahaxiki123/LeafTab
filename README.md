# LeafTab（一叶）

当前最新版本：**v0.6.5 资源管理器快捷入口修复版**（2026-11-15）。

一款面向 **Windows 10 x64（1903~22H2）与 Windows 11 x64** 的轻量级、无广告、零注入多标签资源管理器。

内部直接托管 Windows 官方公开的 `IExplorerBrowser`（`SHELLDLL_DefView`）原生视图控件，外层基于 `.NET Framework 4.8 + WPF` 打造简约高级的 **Apple 风「极简云雾」液态玻璃（Liquid Glass）** 功能区、自适应圆弧连接标签栏（空间不足时可横向滚动并使用标签列表）、极简无框悬浮命令栏、SF Symbols 双色调分层矢量图标体系、可交互面包屑与异步搜索舱。提供轻量级 **图形化一键安装包（约 330.5 KB）**，基于系统自带运行时，零第三方 DLL 依赖。

## 0.6.5 更新内容

- 修复 v0.6.4 中任务栏、开始菜单的文件资源管理器快捷入口及部分文件夹快捷方式点击后没有反应的问题：`SetNoShowUI(true)` 只抑制命令处理过程中的提示，不再用于丢弃已经执行的正常打开命令。
- 保留显式 `SW_HIDE` 请求的隐藏处理、后台 COM 启动隔离、空闲退出保护与原生焦点守卫。
- 补充普通打开、新窗口打开、资源管理器启动 CLSID 与错误提示开关的组合回归；诊断日志区分正常打开、抑制错误提示的打开以及显式隐藏请求。

## 0.6.4 更新内容

- **后台 `--com-server` 静默隔离与跨权限转发加固**：`--com-server` / `-Embedding` 仅启动隐藏 COM 服务，不再编码为打开新标签页请求；已有主进程时以隐藏 COM 转发进程接收实际 `Execute`（为当前用户专属命名管道附加 Medium 完整性标签支持标准 UAC 下普通权限向提权主实例平滑转发，转发失败时自动降级本地打开），无实际打开请求且无可见窗口时于空闲约 30 秒后自动退出，修复输入法或后台组件探测文件夹关联导致已最小化窗口弹出抢焦点的问题。
- **静默 Shell 请求拦截与延迟原生焦点守卫**：该版对 `SetNoShowUI(true)` 的拦截存在回归，已在 0.6.5 修正；窗口处于最小化、隐藏或非当前前台激活窗口时，延迟焦点回调不再清除外部输入焦点或调用 Win32 `SetFocus` / `UIActivate` 激活窗口。
- **最小权限前台授权与生命周期诊断**：IPC 仅为实际打开请求向目标接收进程 PID 授予前台唤醒权限，并在诊断日志补充启动、转发与激活事件名（不记录用户路径与输入内容）。

## 命令行参数

| 参数示例 | 说明 |
| :--- | :--- |
| `LeafTab.exe "D:\Projects"` | 激活已打开该目录的标签页，或在现有窗口新标签页中打开（未运行时直接启动） |
| `LeafTab.exe --new-window "D:\Projects"` | 强制在独立新窗口中打开指定目录 |
| `LeafTab.exe /select,"D:\Projects\README.md"` | 打开所在目录并在文件列表中自动选中定位目标文件 |
| `LeafTab.exe --background` | 静默初始化后台热驻留实例（设为默认资源管理器时用于开机预热，不弹窗） |
| `LeafTab.exe --quit` | 通知正在运行或后台热驻留的 LeafTab 实例完全退出进程 |
| `LeafTab.exe --register-default` | 静默注册当前用户默认资源管理器接管（`Directory / Drive / Folder / Win+E`）并退出 |
| `LeafTab.exe --register-context-menu` | 静默注册文件夹与磁盘右键菜单「在 LeafTab 中打开」并退出 |
| `LeafTab.exe --unregister-shell` | 静默清理仍属于此可执行文件路径的右键菜单与默认资源管理器键值；成功后通知同一路径的后台实例退出，保留其他安装副本 |
| `LeafTab.exe --self-test report.md` | 运行内置自动化断言自检与 1/10/20 标签句柄内存压测（沙盒隔离，不修改真实文件关联；失败返回非零退出码） |

## 编译与运行

### 环境要求
- Windows 10 x64（1903 及以上）或 Windows 11 x64（系统已内置 `.NET Framework 4.8`）
- 编译工具：Visual Studio 2022+（含 `.NET 桌面开发` 工作负载）或 MSBuild

### 命令行构建

.NET SDK 命令行和 Visual Studio MSBuild 均可构建安装器：

```powershell
dotnet build LeafTab.sln -c Release -p:Platform=x64
```

```powershell
msbuild LeafTab.sln /t:Restore,Build /p:Configuration=Release /p:Platform=x64
```
编译产物位于：
```text
src\LeafTab\bin\x64\Release\net48\LeafTab.exe                              # 主程序编译产物（由安装包自动压缩内嵌）
src\LeafTab.Setup\bin\x64\Release\net48\LeafTab-v0.6.5-Setup-x64.exe       # 图形化一键安装包（内嵌压缩主程序与卸载向导）
```

## 隔离验证

```powershell
pwsh -NoProfile -File scripts/verify.ps1
```

脚本将源码复制到新的临时目录，构建主程序和安装器，运行独立回归用例与原生界面自检，输出构建日志、用例结果和性能记录。注册表测试使用随机沙盒，不修改真实文件夹关联；项目内不产生 `bin/obj`。只运行快速回归可加 `-SkipNative`。

开发验收可使用 `LeafTab.exe --self-test-ui <测试目录>...` 打开隔离窗口；该模式跳过会话持久化和系统接管。完整自检命令仍为 `--self-test <报告路径>`。
